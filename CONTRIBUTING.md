# Contributing

Thanks for looking. A few things are worth knowing before you spend time on a change.

## How this repository is maintained

Development happens in a private repository and is exported here. That means:

- Pull requests are read, and accepted changes are applied upstream and exported back.
  Your commit will therefore appear here squashed and reworded rather than merged as is.
  Attribution stays with you.
- Small, focused pull requests are much easier to handle this way than large ones.
- Opening an issue first is worth it for anything beyond a fix, so you do not build
  something that does not fit.

## Ground rules for the code

- **Code and comments in English.** User facing text in the app is German, because the
  users are German speaking fire services.
- **Safety critical calculations are deterministic and tested** against known reference
  values. Isolation distances, breathing air and substance data are not places for
  cleverness. When a value is uncertain, the conservative one wins.
- **Every calculation names its source** in the interface, for example "ERG 2024, Table 1".
- **Bug fixes come with a failing test first.** A test that was green from the start
  proves nothing.
- No hardcoded colours in components, use `constants/colors.ts`.
- No `any`.

## Running the tests

    cd apps/mobile && npm test
    cd apps/mobile && npm run lint
    cd apps/mobile && npx tsc --noEmit
    python3 -m unittest discover -s scripts -p 'test_*.py'

The database tests use a real in-memory SQLite instance, so the SQL itself is under test.
Component tests use React Native Testing Library; note that `render` is asynchronous
there and has to be awaited.

## Substance data

Do not edit `apps/mobile/assets/data/*.json` by hand. Those files are generated by the
scripts in `scripts/` from the BAM data package and from ericards.net. A manual edit is
lost with the next regeneration, and it silently diverges from the regulation.

When the data changes, `scripts/data_version.py` updates `data-version.json`, which is
what makes an installed app reload its database. Both parsers do this on their own.
